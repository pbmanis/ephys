SESSION 4 (2026-09-18 → 2026-09-22) — Direct (non-synaptic) response
separation for LSPS map data   [branch: lsps_direct]
Model: Claude Code (Sonnet 5, switched to Opus 4.8 mid-session via /model)
────────────────────────────────────────────────────────────────────────────────

Goal: separate slow "direct" (non-synaptic, e.g. photocurrent) responses from
synaptic PSCs at LSPS map spots, so synaptic events riding on a direct
response are detected/measured accurately. Considered (a) calling the existing
Julia code (pbmanis/ephys-jl), (b) porting to Python, (c) template approach.
Read the Julia source: the "separation" is a rule-based windowing + derivative-
masked spline/template fit-and-subtract, NOT an exotic method — so ported to
native Python. All work is OPT-IN and OFF BY DEFAULT; existing behavior
unchanged. Full design/progress log also at:
  ~/.claude/plans/in-the-ephys-mapanalysistools-we-linked-shannon.md

──── 4.2  New module: direct_response_separation.py (single-trace, Phase 1) ───

  ephys/mini_analyses/direct_response_separation.py  (NEW, self-contained)
    Pipeline: detect events normally -> subtract_detected_events (subtract each
    detected event's own template scaled to its LOCAL baseline-relative
    amplitude; NOT summary.amplitudes, which is baseline-inclusive) -> fit the
    stimulus window of the residual (fit_direct_component: derivative-masked
    spline with noise-estimated smoothing s, worked in pA/ms; or a normalized
    parametric rise/decay template with adjustable risepower n and 1-2 decays)
    -> subtract the fit from the ORIGINAL trace -> re-detect. Records a
    DirectResponseRecord. separate_direct_response() orchestrates per trace.
    Bugs found+fixed during dev via smoke tests: (i) mindy units (SI vs the
    pA/ms-scaled Julia default) masked nothing; (ii) derivative smoothing
    window must be a fixed small timescale, not scaled to window length; (iii)
    UnivariateSpline smoothing factor is unit-dependent -> set s from an
    estimated noise sigma; (iv) fit window widened (0.12 s) so the direct
    decays within it (removes end-of-window step). measure_events() in
    minis_methods_common.py is NOT used (it reads self.data, unset with
    prepare_data=False, and is otherwise dead) — this module computes its own
    half-width locally to stay self-contained.

──── 4.3  Root-cause fix: HPF-before-detection ───────────────────────────────

  Finding (user insight): AJ/CB detect the slow direct response itself when it
  is the SAME sign as PSCs -> many spurious onsets on the direct's rising
  phase; opposite-sign directs are ignored (explains a sign asymmetry).
  Raising the AJ threshold barely helps (large direct = broad tall criterion).
  Fix: high-pass the trace ONLY for the detection step (DirectSeparationPars.
  detect_hpf, default 100 Hz); amplitudes still measured on the unfiltered
  trace. Same-sign spurious detections 24->4, sign asymmetry gone, spontaneous
  + evoked recall preserved. _highpass() + _detect() helpers added; detection
  onsets now come from the HPF copy in separate_direct_response.

──── 4.4  Phase 2: multi-trace (cross-trace) template estimation ─────────────

  ephys/mini_analyses/direct_response_separation.py
    — estimate_direct_templates(): per trace, event-subtract + take the stim
      window; select direct-containing traces by |window charge| >
      median + k*MAD (k = direct_select_charge_factor; use_qr_selection flag
      reserved for Qr-based selection later, default off). Normalize each
      selected window by its signed peak (canonicalizes scale AND sign),
      average into template(s); optional n_shape_groups clustering (KMeans) and
      "parametric" fit to the average.
    — _robust_amplitude(): Huber IRLS scalar amplitude fit (PSCs/mismatch
      down-weighted).
    — apply_direct_template(): fit template amplitude (+small latency shift) to
      a trace's event-free window, subtract from the raw trace, re-detect.
    — separate_direct_response_map(): two-pass orchestration over a map's
      traces; application gated to direct-flagged traces.

──── get_reader.py (factory) ─────────────────────────────────────────────────
- sniff_format(path) -> acq4|ephus|abf|matdatac|datac|unknown; get_reader(path,
  dataname=, defaults=, fmt=) returns the matching reader instance. Additive:
  importing it changes nothing; acq4 paths still route to acq4_reader.
- Precedence: ephus(.xsg, or lsps_result.mat) > acq4(.index/.ma) > abf(.abf) >
  matdatac(.mat, excl. lsps_result.mat). BFS, shallow markers win.
- datac has arbitrary extensions (recordist initials: .PBM/.HWF/.JSR/.JAW), so it
  is detected by a CONTENT sniff _is_datac() (validates the 128-byte header:
  nr_points, mode, channel count, integral record count) used ONLY as a last
  resort so it never overrides the other formats.
- _is_datac also accepts a HEADER-ONLY datac file (size==128 with a plausible
  nr_points and a text/NUL comment region) so empty/aborted recordings (e.g.
  03JAN97C.HWF) are reported as datac, not "unknown".

  correct. Tested: 3 gapfree VC files + a Bushy IC/VC .abf.
